Vollständige Beschreibung

Für unseren Kunden aus der Logistikbranche in Bern , suchen wir eine:n erfahrene:n, motivierte:n und aufgeschlossene:n Java Fullstack Software Engineer (Spring Boot / Angular).

In diesem Projekt arbeitest du an der Entwicklung einer modernen, skalierbaren Softwarelösung zur datenbasierten Routenplanung und Optimierung komplexer logistischer Prozesse. Gemeinsam mit einem interdisziplinären Scrum DevOps Team gestaltest du eine neue Systemlandschaft auf Basis einer Microservice-Architektur und setzt moderne Technologien sowie Machine Learning ein, um effiziente und zuverlässige Planungslösungen zu ermöglichen.

Deine Aufgaben

  • Entwicklung und Weiterentwicklung moderner Java-Applikationen innerhalb einer Microservice-Architektur
  • Konzeption und Implementierung von Backend-Services mit Java, Spring und Spring Boot
  • Entwicklung und Integration von Frontend-Komponenten mit Angular
  • Implementierung und Anbindung von RESTful APIs sowie Dokumentation mittels Swagger
  • Einsatz von Apache Kafka zur ereignisbasierten Kommunikation zwischen Microservices
  • Containerisierung und Betrieb von Anwendungen mit Docker und Kubernetes
  • Mitarbeit an der Entwicklung datenbasierter Optimierungslösungen im Zusammenspiel mit Machine Learning
  • Sicherstellung einer hohen Codequalität durch Unit Tests, Code Reviews und etablierte Entwicklungsstandards
  • Aktive Mitarbeit in einem interdisziplinären Scrum DevOps Team sowie Mitverantwortung für die Erreichung der Sprintziele
  • Enge Zusammenarbeit mit Softwareentwicklern, Machine Learning Engineers, Business Analysten und UX-Spezialisten
  • Kontinuierlicher Wissensaustausch und Mitgestaltung technischer Lösungen und Architekturentscheidungen

Dein Profil

  • Abgeschlossenes Studium in Informatik, Software Engineering oder vergleichbare Qualifikation durch praktische Erfahrung
  • Mindestens 3 Jahre Erfahrung in der Java-Softwareentwicklung
  • Fundierte Kenntnisse in Java, Spring und Spring Boot
  • Praktische Erfahrung mit Angular und der Entwicklung moderner Webanwendungen
  • Gute Kenntnisse in Apache Kafka sowie im Aufbau und Betrieb von Microservice-Architekturen
  • Erfahrung mit RESTful APIs und Swagger
  • Kenntnisse in Docker und Kubernetes sowie modernen DevOps-Umgebungen
  • Hoher Qualitätsanspruch an Softwareentwicklung, insbesondere Clean Code, Unit Testing und Code Reviews
  • Praktische Erfahrung mit agilen Entwicklungsmethoden und Scrum
  • Selbstständige, strukturierte und lösungsorientierte Arbeitsweise sowie ausgeprägte Teamfähigkeit
  • Sehr gute Deutsch- und Englischkenntnisse in Wort und Schrift
