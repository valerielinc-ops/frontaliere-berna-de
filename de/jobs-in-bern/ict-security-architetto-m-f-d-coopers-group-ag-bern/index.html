Vollständige Beschreibung

Für ein langfristiges und technologisch anspruchsvolles Transformationsprogramm suchen wir für unseren Kunden aus Bern zwei erfahrene ICT Security Architekten.

In dieser Rolle gestaltest du die Sicherheitsarchitektur moderner ICT-Lösungen und begleitest deren Umsetzung von der Konzeption bis zur Integration in den operativen Betrieb.

Deine Aufgaben

  • Erarbeiten und Weiterentwickeln von Sicherheitsarchitekturen für komplexe ICT-Systeme
  • Analysieren und Umsetzen von Security-Anforderungen auf System- und Lösungsebene
  • Erstellen und Pflegen von Architektur-, Security- und Governance-Dokumentationen
  • Begleiten der Umsetzung und Verifikation von Security Features und Security Controls
  • Durchführen von Sicherheitsanalysen sowie Identifikation und Bewertung von Risiken
  • Beraten von Projektteams, Stakeholdern und Lieferanten in Security-Fragestellungen
  • Weiterentwickeln von Informationssicherheits- und Schutzkonzepten
  • Mitarbeit in agilen Entwicklungs- und Architekturteams

Dein Profil

  • Hochschulabschluss in Informatik, Information Security, System Engineering oder vergleichbare Qualifikation
  • Mehrjährige Erfahrung als Security Architect, Security Engineer oder in einer vergleichbaren Rolle
  • Fundierte Kenntnisse in Security Architecture, Cyber Security und Secure Design Principles
  • Erfahrung in der Definition und Umsetzung von Security Requirements und Security Controls
  • Vertrautheit mit Architekturmethoden und dem Erstellen technischer Dokumentationen
  • Erfahrung in komplexen IT- bzw. Integrationsprojekten
  • Kenntnisse im Umfeld Informationssicherheit, Risiko- und Compliance-Management
  • Selbstständige, strukturierte und teamorientierte Arbeitsweise
  • Verhandlungssichere Deutschkenntnisse zwingend
  • Einwandfreier Leumund ist zwingend
